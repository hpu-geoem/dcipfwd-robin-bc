# Inputs of the examples

| Directory | Example of the paper | Generated by |
| --- | --- | --- |
| `ex01-basement-3d/`, `ex02-basement-25d/` | Example 1: two-layer earth, 3D and 2.5D, outer extents 0.5 to 20 km | `scripts/make_examples.py`; `backgrounds/` by `scripts/make_backgrounds.py` |
| `ex03-line48-3d/`, `ex04-line48-25d/` | Example 2: 48-electrode line over the same earth, 1, 2 and 20 km | `scripts/make_examples.py` |
| `e8-overthrust/octree-section/` | Example 3: Overthrust section in 2.5D on quadtree meshes | `scripts/make_overthrust_octree.py section`, `octree_mesh`; `backgrounds/` by `scripts/make_backgrounds.py` |
| `e8-overthrust/octree-volume/` | Example 4: Overthrust volume in 3D on octree meshes | `scripts/make_overthrust_octree.py volume`, `octree_mesh` |

Meshes (`*.mesh`), the voxel models (`voxels.bin`) and the octree models (`model-*`) are not stored; `REPRODUCE.md`
gives the commands that regenerate them. The runs of every example are defined in `scripts/paper_runs.py`.
